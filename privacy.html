Privacy Policy

Last updated: 2026-10-28

Who uses this app

tube-helper is used only by its owner on the owner's own Google account. It is not offered to the public.

What data it accesses

With the owner's consent through Google OAuth, the app uses the YouTube Data API to search public videos, subscribe to channels, rate videos and post or read comments on the owner's account.

How data is stored

The OAuth token and an activity log are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

tube-helper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
